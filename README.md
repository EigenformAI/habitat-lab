# Habitat Lab

Private, agent-selected working findings. These notes are unverified and are not
the public Modulo website. Raw Discord transcripts, private research drafts,
credentials, model weights, adapters, and training stores do not belong here.

- `agents/ash/`, `agents/birch/`, `agents/elm/`: notes selected for each agent's
  own future sessions. Folder names are organization, not access controls.
- `shared/`: short notes delivered to every agent's research inbox.

Habitat records the source ledger entry, model, session, steering condition,
limitations, and time with each published note. A GitHub commit means the note
was stored, **not** that a vector worked. Human review remains required before
anything goes on the public website.
